# 安全部署与事务

开发 Compose 默认只监听 127.0.0.1。APP_BIND_ADDRESS 可以显式更改监听地址；
公开部署前必须替换开发种子管理员、数据库默认密码，并设置站点域名和 TLS。
开发初始化 SQL、测试账号和 test_* 管理接口用于测试环境。测试接口默认返回
404，只有开发环境显式设置 PM_ENABLE_TEST_API=1 后才开启，并继续验证管理员权限。

游戏 JSON API 使用每账号的数据库命名锁和事务。锁在玩家数据读取之前获取，
成功响应前提交；拒绝、异常或提前退出会回滚并释放锁。MariaDB/MySQL 必须
允许 GET_LOCK 和 RELEASE_LOCK；锁、读取与写入必须使用同一个主数据库连接，
不能把插件查询分流到只读副本。所有 pm_* 表必须使用 InnoDB。迁移旧站时
先执行 migrations/from-x3/001_x3_to_x5_migration.sql，再部署插件。锁等待
超过 10 秒时返回 409，客户端可以稍后重试。不同账号仍可同时使用。

is_open 对游戏 API 同样生效。论坛管理员与配置的宠物管理员保留维护访问；
测试管理 API 继续使用自身的权限检查。图片徽章和头像不使用游戏事务。

话题摘要只显示公开版块，检查父版块限制，并按照当前用户阅读权限过滤帖子。
密码、指定群组或公式限制版块请使用论坛原生页面访问。

旧 plugin/index.php 文件代理已停用并返回 404。图片与 WASM 资源由静态服务器
从 images/、wasm/ 目录直接提供。若旧部署有指向该代理的自定义重写，应更新
为固定静态资源路径，不能把任意请求路径交给 PHP 读取。

执行 just test-php 会运行结构／语法检查和离线安全行为测试。并行交易整合
测试可通过 scripts/test/security_transactions_db.php 在隔离的测试数据库运行，
连接参数由环境变量提供；该测试只创建并删除自己生成的测试表。
